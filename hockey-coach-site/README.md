# Hockey Coach — демонстрационный лендинг

Адаптивный сайт для портфолио: индивидуальные хоккейные тренировки. Проект сделан на чистом HTML, CSS и JavaScript, чтобы его можно было открыть локально, разместить на статическом хостинге или использовать как референс для сборки в Tilda / Zero Block.

## Как открыть

1. Распакуйте архив.
2. Откройте `index.html` в браузере. Для удобной работы можно использовать Live Server в VS Code.
3. Файлы стилей и скрипта подключены отдельно: `styles.css` и `script.js`.

## Что реализовано

- адаптивная главная страница;
- мобильное меню;
- якорная навигация;
- блоки программ и форматов тренировок;
- цены, которые можно редактировать;
- FAQ на нативном `<details>`;
- форма заявки с проверкой обязательных полей и подготовкой письма через `mailto:`;
- состояния hover / focus и поддержка reduced motion.

## Обязательно поменять перед показом клиентам или публикацией

1. Имя / бренд тренера, город и реальные площадки.
2. Все демонстрационные цены и условия.
3. Контактный адрес в `script.js` — замените `hello@example.com` на рабочую почту. Сейчас форма намеренно не отправляет данные на сервер и показывает подсказку, пока стоит адрес-заглушка.
4. Добавьте реальный телефон / Telegram, политику конфиденциальности и согласие на обработку персональных данных.
5. Замените демонстрационные тексты на фактические данные тренера. Не публикуйте вымышленные достижения, отзывы или сертификаты.
6. Проверьте лицензию и актуальность фотографий перед коммерческой публикацией.

## Перенос в Tilda / Zero Block

Рекомендуемая структура страницы:

1. Header — логотип, меню, кнопка записи.
2. Hero — фон с хоккейной фотографией, заголовок, описание, две CTA-кнопки.
3. Intro — короткое позиционирование и философия.
4. Programs — три карточки направлений.
5. Approach — фото и три шага методики.
6. Results — четыре навыка / результата.
7. Pricing — три тарифные карточки.
8. Contact — форма заявки.
9. FAQ — раскрывающиеся вопросы.
10. Footer — логотип, подпись, верх страницы.

В Zero Block собирайте каждый крупный раздел отдельным блоком. Задайте max-width контента около 1200 px, используйте отступы 32 px на десктопе и 16–20 px на телефоне. Для карточек на мобильном переключите сетки в одну колонку. Изображения лучше загрузить в библиотеку проекта Tilda, а не оставлять внешние ссылки на Pexels.

## Важные замечания

Это демонстрационный проект для портфолио, а не готовый сайт конкретного тренера. В нём нет серверной отправки заявок, CRM, онлайн-оплаты или аналитики. Для этих функций нужно подключить реальные сервисы и протестировать их до запуска.
